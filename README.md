# Electricity Bill Management System

## About
A console-based electricity billing system developed using C.

## Features
- Customer registration
- Electricity unit calculation
- Slab-based bill calculation
- Fixed charge calculation
- Bill generation

## Technologies Used
- C Programming
- Structures
- Functions
- Conditional Statements

## How to Run
Compile the program using GCC:

gcc main.c -o electricity

Run the program:

./electricity
